# ComfyUI Fix Model Paths 🦊

[English](README.md) | [Русский](README.ru.md)

Исправляет сломанные пути к моделям в workflow ComfyUI, пытаясь найти такое же имя (или нужный вариант) в подпапках.

## Установка

Скопируйте или склонируйте папку плагина в:

```text
ComfyUI/custom_nodes/
```

Перезапустите ComfyUI.

Дополнительные Python-пакеты не нужны.

## Как пользоваться

### Исправить весь workflow

- Откройте workflow в ComfyUI.
- Кликните правой кнопкой по пустому месту на холсте.
- Нажмите `Fix Model Paths 🦊`.

Плагин попробует заменить отсутствующие пути на подходящие локальные модели.

### Исправить один узел вручную

Используйте это, если автоматическое исправление не смогло выбрать правильную модель.

- Кликните правой кнопкой по сломанному узлу.
- Нажмите `Fix Node 🦊`.
- Выберите правильную модель в самом узле.
- Подтвердите замену
  - или снова кликните по узлу правой кнопкой и нажмите `Save Fixed 🦊`.
  - или нажмите `Save Fixed 🦊` на появившемся меню в левой верхней части ноды.

Сохраненное исправление будет использоваться в следующий раз.

### Найти отсутствующую модель

Кликните правой кнопкой по сломанному узлу и нажмите `Find Model 🦊`.

Откроется веб-поиск по имени отсутствующей модели.

## Правила сопоставления

Имена сопоставляются «мягко»: регистр и разделители не важны (`flux_dev` = `FluxDev`), слова про точность и квантование (`fp8`, `bf16`, `Q4_K_S`, `e4m3fn`, `scaled` и т.д.) игнорируются.

Настройка:

```text
ПКМ по канвасу -> Model Name Rules 🦊
```

- **Ignored words**: свои слова вроде `kj` или `comfy-org`, а также отключение встроенных групп.
- **Aliases**: считать одно слово другим, например `encoder` = `enc`.
- **Saved replacements**: точные замены, сохранённые через `Save Fixed 🦊`; неверные можно удалить.

Всё правится кнопками, JSON вручную не нужен. Правила хранятся в `model_matching_rules.local.json` (при каждом сохранении остаётся копия `.bak`); старые «постфиксы» автоматически становятся игнорируемыми словами. После `Save Fixed 🦊` плагин может предложить запомнить замену как общее правило. Номера версий (`2509` и `2511`) в правила не превращаются.
